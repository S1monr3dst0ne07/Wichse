
# WICHSE - Windows Integriertes Computer Hoch-Sprachen Entwicklungsprojekt
Die meisten Programmiersprachen beziehen Bezeichnernamen aus der englischen Sprache.
Wichse, hingegen, bezieht Bezeichnernamen aus dem Deutschen. 
Sprache der Dichter und Denker! Und Wichser.

Programme werden zu nativen, ausführbaren Windows Dateien kompiliert.
Hierzu wird FASM als Hinterbau verwendet. Es ist zu erwähnen, dass
der Kompiler alle Importierungstabellen selbst erzeugt.
Somit können Wixprogramme direkte Aufrufe zur Win32 API tätigen.
